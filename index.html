Run it from a local server

This page was opened straight from disk (file://). Browsers refuse to load JavaScript modules over file:// for security, so the storefront would render blank. Serving the folder over http:// fixes it — there is no build step and nothing to install for the site itself.

01VS Code (easiest): install the Live Server extension, then right-click NEXORA.dc.html in the explorer → Open with Live Server.
02Python: open a terminal in this folder and run python3 -m http.server 8080 — on Windows use py -m http.server 8080.
03Node: npx serve . or npx http-server -p 8080.
04Then open http://localhost:8080/NEXORA.dc.html. Shortcut scripts serve.sh (macOS/Linux) and serve.cmd (Windows) are included.

Keep the folder intact: NEXORA.dc.html, ProductCard.dc.html, support.js, the three nexora-*.js files, assets/ and _ds/ must stay side by side. An internet connection is needed on first load for three.js and the webfonts.
